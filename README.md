# 🚀 Nova AI – Personal Learning Assistant

## 📌 About the Project

Nova AI is a simple, interactive chatbot designed to help users learn about different topics, including Artificial Intelligence, Machine Learning, Programming, Science, and Indian General Knowledge.

The project is built using HTML, CSS, and JavaScript. It provides a clean interface where users can ask questions and receive predefined answers instantly.

## ✨ Features

- **Interactive Chatbot:** Send messages and receive responses.
- **Four Learning Categories:** Artificial Intelligence, Machine Learning, Programming, and Science.
- **Indian General Knowledge:** Get answers to common questions about India.
- **Dark and Light Mode:** Switch between two themes.
- **New Chat:** Start a fresh conversation.
- **Chat History:** View conversations during the current session.
- **Typing Indicator:** Shows when Nova AI is preparing a response.
- **Responsive Design:** Works on desktop and mobile screens.

## ▶️ How to Run the Project

1. Download or clone the project.
2. Extract the ZIP file if downloaded.
3. Open the Nova AI folder.
4. Double-click `index.html` to open it in your browser.
5. Start chatting with Nova AI!

You can also open the folder in Visual Studio Code and run it using the Live Server extension.

## 🎯 Project Objective

The main objective of Nova AI is to create a beginner-friendly learning assistant that makes it easier for users to explore basic concepts in technology, science, and general knowledge.

## ⚙️ How It Works

Nova AI uses JavaScript to identify keywords in the user's message and match them with predefined responses stored in its knowledge base.

The chatbot displays the matching answer in the conversation window.

**Note:** This version uses a predefined knowledge base and does not connect to an external AI API or generate answers dynamically.
